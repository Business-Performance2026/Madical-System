# عيادتي - نظام حجز مواعيد العيادات

نظام ويب بسيط لحجز مواعيد العيادات، يخدم ثلاثة أنواع مستخدمين: **المريض**، **العيادة**، و**الأدمن**.

## نبذة عن المشروع

### أنواع المستخدمين

**1. المريض**
- إنشاء حساب (اسم، بريد إلكتروني، كلمة مرور)
- البحث عن العيادات واختيار الطبيب
- اختيار التاريخ والوقت من الأوقات المتاحة فقط
- إرسال طلب حجز ومتابعة حالته (قيد الانتظار / مقبول / مرفوض)
- عرض المواعيد القادمة والسابقة

**2. العيادة**
- تسجيل حساب (يتطلب موافقة الأدمن قبل التفعيل)
- إضافة أطباء وتحديد أوقات عملهم
- استقبال طلبات الحجز وقبولها أو رفضها
- عرض جدول المواعيد اليومي والأسبوعي
- البحث عن المرضى

**3. الأدمن**
- الموافقة على تسجيل العيادات
- إدارة جميع العيادات والأطباء
- إيقاف أو حذف أي حساب
- عرض جميع الحجوزات ولوحة إحصائيات

### الميزة المميزة للتطبيق
عند قبول حجز لوقت معين، يُقفل ذلك الوقت تلقائياً ولا يمكن لأي مريض آخر حجزه — يمنع تداخل المواعيد ويسهّل إدارة الجدول.

### الهوية البصرية
- ألوان هادئة: أزرق طبي، أبيض، رمادي فاتح
- تصميم بسيط، أيقونات واضحة، أزرار كبيرة
- مناسب لكبار السن من ناحية سهولة الاستخدام

## القرارات التقنية

| القرار | الاختيار |
|---|---|
| نوع المشروع | موقع ويب بسيط (HTML / CSS / JS) |
| قاعدة البيانات والمصادقة | Firebase (Authentication + Firestore) |
| طريقة تحميل Firebase SDK | Compat SDK عبر `<script>` من CDN (بدون أدوات بناء مثل Vite/Webpack) |
| الاستضافة المخطط لها | GitHub |
| اتجاه الصفحة | RTL / عربي |
| الخط | Tajawal (خط عربي واضح ومريح لكبار السن) |

## ما تم إنجازه حتى الآن

تم بناء **نقطة الدخول** (`index.html`) لكامل التطبيق، وتشمل:

- شاشة موحّدة لتسجيل الدخول وإنشاء حساب جديد
- عند إنشاء حساب: اختيار نوع الحساب (مريض / عيادة)
- ربط مباشر مع Firebase Authentication (بريد إلكتروني + كلمة مرور)
- عند التسجيل، يُنشأ مستند للمستخدم في مجموعة `users` بـ Firestore بالحقول:
  - `name`, `email`, `role` (`patient` / `clinic` / `admin`), `status`, `createdAt`
- حساب العيادة يُنشأ بحالة `pending` تلقائياً، ولا يقدر يسجّل دخول حتى توافق عليه الإدارة
- بعد تسجيل الدخول، توجيه تلقائي حسب نوع الحساب:
  - مريض → `patient/home.html`
  - عيادة → `clinic/dashboard.html`
  - أدمن → `admin/dashboard.html`
  - (هذه الصفحات الثلاث لم تُبنَ بعد)
- رسائل خطأ مترجمة للعربي (بريد مستخدم، كلمة مرور ضعيفة، بيانات خاطئة...)

### هيكل الملفات


## قبل التجربة - إعدادات مطلوبة على Firebase Console

1. **Authentication** → Sign-in method → تفعيل **Email/Password**
2. **Firestore Database** → إنشاء قاعدة بيانات (Test mode مؤقتاً للتجربة، ثم تشديد الصلاحيات لاحقاً)
